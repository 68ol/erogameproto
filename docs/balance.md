# 밸런스

수치는 모두 `src/js/05-balance.js`에 있다. 바꾼 뒤에는 반드시 시뮬레이션을 돌린다.

```bash
./build.sh && node scripts/balance-sim.mjs 30 8   # 30일 × 8회
```

## 설계 의도: 두 개의 하락 축

| 축 | 오르는 원인 | 의미 |
|---|---|---|
| **트라우마** | 끝까지 버티다 패배, 기절, 붕괴, 높은 스트레스·고통 상태 유지 | 강제로 당한 것의 누적 |
| **자제력 하락 / 순종 상승** | 스스로 받아들임 | 스스로 무너지는 것의 누적 |

저항하는 플레이어는 트라우마가 오르고, 받아들이는 플레이어는 자제력이 떨어진다. 어느 쪽도 공짜는 아니다.

## 목표와 현재 결과 (30일, 8회 평균)

| 성향 | 목표 | 트라우마 | 자제력 | 결과 |
|---|---|---|---|---|
| 신중 (밤 외출 안 함, 도주 위주) | 트라우마 < 150, 자제력 > 800 | 0 | 1000 | 충족 |
| 보통 (무작위 이동, 받아들임 10%) | 트라우마 150~450, 자제력 500~900 | 187 (134~281) | 760 | 충족 |
| 무모 (밤거리 선호, 항상 받아들임) | 자제력 < 300, 트라우마 ≥ 200, 15일 내 1000 금지 | 353 | 164 | 충족 |

## 이번 조정에서 고친 것

| 문제 | 원인 | 수정 |
|---|---|---|
| 신중하게 플레이해도 30일에 기절 50회 | 피로 69에서 4시간 알바를 시작할 수 있었음 | 피로 60 이상이면 근무 불가, 하루 1회 |
| 하루 평균 조우 1.7회 | 밤에 광장·번화가를 지날 때마다 확률 판정 | 낯선 사람 조우는 하루 최대 2회 (`groupPerDay`) |
| 무모한 플레이가 보통보다 트라우마가 낮고 자제력이 1000 유지 | 자제력이 매시간 +2(하루 48) 회복돼 패널티가 상쇄됨 | 자제력은 잘 때만 +15 회복 |
| 저항이 거의 성공하지 않음 (48회 중 승리 1, 탈출 8) | 평균 NPC 상대 도주 성공률이 바닥인 5% | 난이도 계수를 낮춤 → 시작 시 도주 약 45% |
| 돈을 쓸 데가 없음 (30일에 98만) | 지출 없음 | 생활비 하루 20,000, 마이너스면 스트레스 |
| 기절 패널티가 과함 | 기절 1회 트라우마 +10 | +5 (6시간 소모 자체가 패널티) |

## 남은 문제

1. **신중한 플레이에 아무 일도 안 일어난다.** 트라우마 0, 조우 7회. 안전하게 플레이하면 콘텐츠를 거의 못 본다. 낮 이벤트(네임드 NPC 접근, 알바 중 사건)가 생기면 해결될 문제지만, 지금은 시스템상 밤만 피하면 끝이다.
2. **신중한 플레이는 돈이 계속 쌓인다** (30일 77만). 옷, 월세, 학비 같은 지출처가 생길 때 다시 맞춰야 한다.
3. **무모한 플레이는 순종이 25일 전후로 100에 닿는다.** 상한에 붙은 뒤에는 변화가 없다. 순종 단계별 특성이나 이벤트가 생기면 상한을 늘리거나 증가량을 줄여야 한다.
4. **스킬이 오르지 않는다.** 운동을 올릴 수단이 없어서 조우 성공률이 30일 내내 같다. 체육관 같은 성장 수단이 필요하다.
5. 시뮬레이터의 성향 3종은 근사치다. 실제 플레이어는 반복 탈출 루트처럼 최적화를 하므로, 콘텐츠가 붙으면 실제 플레이 테스트로 다시 확인해야 한다.
